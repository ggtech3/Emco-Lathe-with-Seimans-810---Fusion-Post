# Validation workflow

For each behavior change, identify representative operations and expected NC output. Preserve baseline output from the owner-reported version. Post the same inputs with the candidate and compare tool changes, coordinates, units, offsets, retracts, cycles, spindle and coolant behavior as applicable. Record intentional differences and failures. Review generated NC before any machine use. Record machine validation separately with owner, date, exact revision and tested operations. No test jobs or machine results were supplied during migration.
